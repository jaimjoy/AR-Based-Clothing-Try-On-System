# AR-Based-Clothing-Try-On-System
Our project is an AR-Based Clothing Try-On System that helps users virtually try clothes using their smartphone camera before purchasing online. The main problem we address is the high return rate in e-commerce (20-40%) caused by wrong size, poor fit, and uncertainty about appearance.

To solve this, our system uses Augmented Reality and body measurement detection to overlay 3D garments on the user in real time. Users can view clothes from front, side, and back, capture screenshots, save try-on sessions, and receive AI-based size recommendations based on their measurements.
We followed the Scrum process model because AR development involves high uncertainty and needs continuous feedback. The project was planned in 6 sprints, gradually delivering features like AR try-on, measurement detection, product catalog, and checkout.

The system includes modules such as authentication, AR try-on core, body measurement, product catalog, size recommendation, session management, and payment integration.

We also designed 12 detailed test cases (TC-01 to TC-12) to verify functionality, performance, and usability. Overall, the project improves customer confidence, reduces returns, and supports a modern, sustainable online shopping experience.
